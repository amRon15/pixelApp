# Pixel Drawing app

## Overview
The Pixel Art App is a creative tool designed for pixel art enthusiasts. With an intuitive interface and powerful features, you can easily create, preview, and export pixel art creations. The app supports a 16x16 grid layout where each cell can be customized with your chosen colors. It also allows you to manage multiple pixel art projects, export them as JPEG or GIF files, and preview them directly within the app.

## Features
- The app provides a 16x16 grid layout, enabling detailed pixel art creation.
- JPEG Export: Save your pixel art as a static image in JPEG format.
- GIF Export: Create animated GIFs using multiple frames of pixel art.
- Support for both JPEG and animated GIF previews in app.
- Save and store multiple pixel art projects for later use.
